# AVALON — Back-End

Back-end (API REST) da plataforma **AVALON**, desenvolvido pela equipe **Nexus**, seguindo os requisitos funcionais, não funcionais e regras de negócio documentados no [repositório central](https://github.com/Daniele-SS/NEXUS).

## Documentação da API

A especificação completa da API está em [`openapi.yaml`](openapi.yaml) (OpenAPI/Swagger 3.0.3), cobrindo Colaborador, Setor, Cargo, Jornada, Férias, Benefício, Documento, Feedback, Pesquisa, Indicador, Avaliação Psicossocial, Motor de Regra, Planos de Ação, Relatório, Notificação, Acesso e Auditoria.

Para visualizar de forma interativa, cole o conteúdo do arquivo em [editor.swagger.io](https://editor.swagger.io/).

## Estrutura

- `controller/app.js` — ponto de entrada da aplicação
- `openapi.yaml` — especificação OpenAPI/Swagger da API
